# DS04-001 디자인 명세
- 이름: 현장 포켓 / 문구: 한 걸음씩, 더 나은 매대.
- 바탕 #F5F3EE, 종이 #FFFFFF, 글자 #24342D, 보조 #55665D, 선 #ABB6AC, 주색 #245541, 강조 #C95729. 준수 #236247, 개선 #93440E, 중립 #4D5964. 상태마다 글자 병기.
- 시스템 한글 산세리프. h1 32/40 desktop·27/35 mobile, 본문16/25, 보조14/21. 8px 리듬, 카드24px padding·20px radius, 버튼 최소48px, form label14px. 검은 그림자 대신 얇은 선.
- 상단 얇은 브랜드/역할/로그아웃. 중앙 max1120px. 점주 제출 max720px. 하단 5개 이하 탭 고정, 추가 업무는 ‘더보기’라는 별도 화면의 큰 링크 행. 상단에도 현재 역할·범위를 표시한다.
- 모바일390: 단열·너비100%, 페이지 바닥100px 안전공간, 사진 원본 contain, 입력16px, 바닥 주요액션48px. desktop1440: 카드 2~3열, 상세 근거와 보조정보 2열. 폼은 단계별 또는 접히는 section으로 긴 페이지 부담을 줄인다.
- 제출 stepper는 1 매장 2 사진 3 질문 4 확인. 다음은 현재 단계 검증 뒤 이동, 이전으로 돌아가도 파일/질문 보존. 파일당 삭제·앞뒤 순서 변경. 네트워크 재송신은 같은 멱등키 유지.
- 목록 필터는 접히는 ‘조회 조건’, 적용값은 URL. 목록 반환 후 페이지 보존. 차트 옆 표·null 이유; 제출없음/판단불가/기술실패 각각 분리.
- 모든 route는 h1 한 개. semantic main/nav/form, label 연결, focus2px, aria-live 상태, 키보드 탭 접근. 오류에 재조회 버튼과 안전문구; 원시 JSON/구현 정보 노출 금지. 실패를 임의 결과로 대체하지 않는다.
- 운영 변경은 이유 입력→내용 확인(같은 화면 두번째 단계)→확정. 기존 연결 종료/접근변경을 문장으로 설명하며 기존 version 전송. 비밀번호는 저장/노출하지 않는다.
