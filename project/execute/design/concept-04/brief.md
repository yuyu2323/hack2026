# DS04-001 / 현장 포켓
상태: 구현 정본 v1.0, 독립 최종 검수 대기. 기준: docs04의 모바일 현장.

점주는 서서 한 손으로 사진을 제출하고, 영업 담당자는 이동 중 한 건의 근거와 다음 행동을 확인한다. 플랫폼 운영자도 영향과 이유를 확인한 뒤 변경을 마친다. 모든 기능은 하나의 빌드에서 역할별로 분리한다.

시안 01의 밀도 높은 관제표, 02의 작업 lane, 03의 사진 inspector와 달리 이 시안은 아래 탐색, 큰 선택 행, 한 번에 한 단계인 사진 제출, 순차 안내 중심이다. 데스크톱은 중앙 작업지와 보조 정보로 확장하며 사이드바를 쓰지 않는다. 첫 화면은 큰 대표 행동과 오늘의 현장 상태이고 숫자 표가 주인공이 아니다.

점주: 매장 선택 → 사진 → 질문 → 확인 → 전송. 영업: 확인할 매장 카드 → 한 제출의 근거 → 조치. 운영: 현재 상태 → 변경할 대상 → 입력 → 영향 확인 → 실행. 동일 업무 범위는 docs03·04·06을 모두 따른다.
