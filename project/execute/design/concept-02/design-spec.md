## 업무 화면
- 로그인: 왼쪽 브랜드/3단계 소개, 오른쪽 인증 카드. 모바일은 인증 카드 우선.
- 점주 첫 화면: 큰 “사진으로 점검하기” 다음 행동 카드와 연결 매장 선택; 대기/결과/완료 업무 카드.
- 영업 첫 화면: 검토→조치→후속 확인 lane, 각 카드의 문제와 다음 행동. 미제출/판단불가/기술실패 별도 문구.
- 운영 첫 화면: 실패 복구·연결 누락·상태 확인 작업 lane. 실제/Mock 장애를 분리.
- 상세: 업무 맥락과 단계 rail, 사진 근거/판정, 적용 기준/Reference, 후속 CTA. 폼은 본문에 펼쳐 키보드 이동이 자연스럽게 한다.
- 관리: 상단 설명/생성 폼과 작업 카드 목록. 버전·범위·사유를 명시한다. 위험 변경은 영향 안내와 사유를 필수로 요청.
- 분석: 서버 값으로 추이 막대와 상관 산점도, 모든 점의 데이터 표. Mock/표본/계산불가/인과아님 표시.

## 상태·접근성
- pass 녹색+준수, fail 주황+개선 필요, unknown 회색+판단 불가. 색만으로 구분하지 않는다.
- 최초 로딩 aria-busy, 갱신 기존 내용+상태, 빈 화면 안내/필터초기화, 오류 safe message/request_id+재조회.
- 401/403/404 현재 화면 데이터 제거. 로그인 return URL은 같은 역할 prefix만 허용.
- polling 2초·터미널 종료·복귀 즉시, 지연안내30초. 네트워크 오류는 분석실패로 변경하지 않는다.
- 필터·페이지 URL 유지; h1 한 개, nav/main/form/label, 모든 기능 키보드 가능, 페이지 전역 가로 overflow 금지.
