# DS02-001 · 독립 검수 기준
검수자는 각 항목 PASS/FAIL/BLOCKED/NOT_RUN과 실제 화면 증거를 기록한다. 작성/개발자 자체 체크를 독립 PASS로 쓰지 않는다.

1. 1440×900 영업 첫 화면이 3단계 업무 lane으로 보이며 KPI 표 중심01과 정보구조가 구별된다.
2. 390×844 점주에서 다음 행동·매장 선택·사진 제출이 첫 화면에서 명확하다.
3. 운영 첫 화면은 복구/연결/상태 작업과 안전한 메타데이터만 표시한다.
4. 다섯 역할의 메뉴·직접 경로 제한이 현재 세션 역할과 일치한다.
5. 사진 선택/미리보기/순서/삭제/장수·용량 오류와 질문 글자수가 사용 가능하다.
6. queued/running/지연/실패/unknown/성공이 다른 문구와 다음 행동을 가진다.
7. 결과의 질문 답·기준별근거·Reference·제한·준수율/판단가능률/null이 빠짐없다.
8. 생성이미지/Mock/실제AI 배지가 출처를 혼동시키지 않는다.
9. 재제출→부모 연결→전후 사진·변경 기준 안내가 이어진다.
10. 영업 보드에서 동일 필터로 원본·이슈를 확인하고 담당/상태/조치를 기록한다.
11. 기준4단계/새버전/Reference교체·비활성 UI와 현재 권한이 일치한다.
12. 계정/매핑/지역·매장·카테고리 관리에 사유/버전충돌/영향 안내가 있다.
13. 실패재처리는 failed+can_retry일 때만 가능하며 attempts를 보존해 표시한다.
14. 추이·산점도·데이터표는 서버 값이며 Mock·표본·계산불가가 표시된다.
15. 알림 읽음/링크와 공지 작성·유효 공지 표시가 동작한다.
16. 모든 입력 라벨, 44px 주요 버튼, 3px 초점, 키보드로 핵심 흐름이 가능하다.
17. 모바일/200%확대에서 페이지 전체 가로스크롤 없이 사용 가능하다.
18. 최초로딩/갱신/빈상태/오류와 재조회, 민감데이터 제거가 실제 동작한다.
19. URL 필터/페이지 및 뒤로가기에서 작업 맥락이 보존된다.
20. npm build/test 성공과 독립 실제브라우저/AI 실행 증거는 별도로 인계된다.
