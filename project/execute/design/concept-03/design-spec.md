# DS03-001 디자인 명세
구현 선행 디자인 v1.0. 공통 API CONTRACT-DATA-1.0b, 화면 PD-002와 호환.

## 시각 체계
따뜻한 종이 바탕 #f5f3ef, 표면 #ffffff, 본문 #202824, 보조 #53615a, 테두리 #b2bcb5. 강조 forest #24573d, 선택 mint #e1eee4, 개선 #8c4218, 오류 #a72833. 제목은 serif로 전시 제목처럼, 본문은 OS 한글 sans-serif로 읽는다. 본문16px/1.6, 보조13px, H1 clamp28~46px. 간격8/12/20/32/48px, 모서리 카드4px, 배지100px. focus는3px #276940+offset3px.

## 구조와 화면
- 전체 최대1440px, 여백 desktop40px/mobile16px. 상단 브랜드·역할·계정, 아래 작업 도구막대는 overflow 자동이며 현재 페이지 aria-current.
- 점주 홈: 인사·사진 제출 CTA → 매장 선택 → 사진 contact sheet(데스크톱3열/모바일1열) → 문의 링크. 사진 카드 아래 날짜/매장/카테고리/처리·실제AI·Mock 출처.
- 제출: 01범위·02사진·03질문을 한 화면의 세로 스튜디오 시트로 배치, 사진 순서/제거·재제출원본 안내. 미리보기 정사각형, 결과원본은 contain.
- 결과: 왼쪽60% 큰사진/번호 선택, 오른쪽40% 질문 답·준수/판단 가능률·기준 판정/근거/행동. 아래 접기 가능한 적용 기준 및 Reference snapshot, 연결 이슈와 재제출 타임라인. 사진 근거 버튼은 해당 사진으로 이동.
- 영업 홈: 범위 필터 → 최근 사진 contact sheet → 하단 보조지표띠·매장별 상태 시트. 첫 viewport는 사진을 주정보로 두고, 상단 `지표·매장 현황 ↓`과 하단 `사진으로 돌아가기 ↑`로 이동한다. 동일 filters로 drilldown하며 KPI·표본·매장별 상태를 유지한다. 기준은 텍스트 세부시트, Reference는사진갤러리.
- 비교: 이전/현재 두 사진 column과 공통rule 변화행. 기준변경/unknown은 비교불가로 표시.
- 이슈: 왼쪽선택목록·오른쪽조치기록. 관리자 상태/담당자/우선순위/다음점검/해결사유 변경. 점주는 읽기 및 자기 제출 문의.
- 분석: 추이 막대와 수치표·Mock 상관 산점도와 표본/제외 수·기간 집계표. null을0으로 대체하지 않음.
- 운영: 상태 계기+요청/attempt 시간선. 영업사진·질문·평가를 API로 요청하지 않음. 계정/기준 정보는선택목록+입력 inspector. 계정 role/store mapping과version/reason, 비활성 영향확인. 감사는읽기만.

## 상호작용·4상태
처음 로딩은 skeleton, 갱신시 기존 내용과 갱신표시. 실패는 안전한message/request ID와 명시적 재조회. 401 세션폐기/403 데이터폐기. 빈상태는조건초기화 또는생성CTA. 2초job polling은queued/running만,30초후지연안내,끝나면중단. 변경중중복버튼방지,실패시입력유지,명시재시도동일멱등키. 성공후서버다시조회. 검색/페이지URL보존과내부이동뒤로가기. 인증정보 저장하지않음.
