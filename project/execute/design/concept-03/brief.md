# 시안 03 — Evidence Atelier / 사진과 근거
버전 DS03-001, 작성 2026-09-21, 담당 concept03. 공통 G1 계약 유지.

사진을 먼저 펼쳐 보고 질문·평가 근거를 함께 읽는 작업실이다. 영업 관리자는 contact sheet에서 매장의 실제 제출 사진을 선택해 왼쪽 큰 이미지와 오른쪽 근거 inspector를 연다. 점주는 동일한 시각 언어로 개선 전후의 변화를 기록한다. 운영자는 사진 권한이 없으므로 요청과 attempt의 시간 관계를 세로 타임라인으로 탐색한다.

탐색은 상단 브랜드/계정과 별도의 얇은 작업 도구 막대로 구분한다. 첫 화면은 숫자 table이나 우선순위 보드가 아닌 넓은 사진 contact sheet다. 왼쪽 고정 메뉴는 두지 않는다. 사진 보기와 세부 설명이 화면의 중심이며 KPI는 작은 필름 정보띠로 보조한다. 모바일에서는 inspector가 사진 아래로 이어지고 모든 주요 터치는44px 이상이다.

공통 필수 기능을 모두 제공한다. 권한 밖 메뉴/이미지를 숨기며 실제 서버 권한 검사를 사용한다. Mock 평가·AI 생성 시연 사진·실제 AI 결과를 따로 표시한다. 최종 시안 선택은 사용자에게 남긴다.
