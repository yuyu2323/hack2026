## 보고서 형식과 수정 절차

보고서에는 소스/빌드 식별자, 명세 버전, 데이터 버전, 브라우저·viewport, role·route·state, 기대/실제, PASS/FAIL/BLOCKED/NOT_RUN, 실제 캡처 링크, 수정 담당·재검수 결과를 기록한다. UI 수정은 같은 기준으로 재검수하며 매뉴얼 캡처와 기능 회귀도 갱신한다. 기준을 사후 완화해 통과시키지 않는다.

스크린샷 파일명은 `D01-<기준>-<role>-<screen>-<state>-<viewport>.png`로 정하되 실제 촬영한 내용과 일치해야 한다. 비밀번호/세션·CSRF 값·외부 실제 영업정보가 들어간 증거는 인계하지 않는다.

- D01-17 역할 경계 회귀: 플랫폼 운영자 화면에 영업 알림 링크·라우트가 없고 `/notifications`를 요청하지 않는다. 공통 운영 공지와 운영 공지 관리는 유지된다. WEB01-004 단위 검증과 별도로 실제 브라우저 확인.
