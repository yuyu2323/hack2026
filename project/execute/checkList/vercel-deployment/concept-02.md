# 시안 02 Vercel 배포 준비

- 범위: codex/concept-02만 변경. main 및 상위 계약 문서 유지.
- 변경 이유: 심사위원용 Vercel 프론트와 외부 Docker 백엔드 연결을 환경변수로 재현 가능하게 구성.
- 영향: Vercel 전용 빌드 출력, HTTPS 프록시, SPA 라우팅, 환경 생성 CLI 및 배포 문서. 기존 로컬/Docker 빌드 유지.
- 검증: 잘못된 origin 차단, API/SPA 경로 분리, 실제 프론트 빌드, 환경 생성 호환성, 독립 검토.
- 외부 Vercel 배포·실제 업로드 프록시·GPT 유료 호출은 별도 실행이며 로컬 검사로 대체하지 않음.
