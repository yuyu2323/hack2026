## 후속 증거 범위

초기 전체 재촬영 목록은 이력이며 현재 요청은 [통합 잔여 목록](../../workHitory/frontend-comparison/pending-visual-evidence.md)을 따른다. 정상 비교·지역/HQ 보드·unknown·감사/시도 화면은 반복하지 않는다. Reference 번호는 새 파일의 대상이 화면 밖이므로 해당 구간만 후속 확인한다.

키보드 조작의 성공과 정보 변경은 root 기능 기록을 함께 참조하지만, DOM 존재만으로 최종 디자인 PASS를 주지 않는다.
