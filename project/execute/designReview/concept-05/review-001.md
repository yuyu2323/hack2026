운영 첫 화면은 계정↔매장 연결을 앞에 두고 실제 작업과 Mock 장애를 구분한다. 영업 알림 메뉴와 사진/질문/평가 본문이 없고 공통 공지는 표시된다. 계정 비활성 후 빈 로그인, 매핑 철회 후 업무본문 없는 접근 불가를 직접 확인했다. 두1280 파일의 높이는720 계열로, docs09의1280×800 추가검수와 혼동하지 않도록 원본 크기를 기록하고 root에 전달했다.

미연결 계정의 빈 이력은0건/페이지 비활성과 미제출 의미를 안내한다. 역할 변경 후 기존 경로는 본문 없이 거부하고, OFC 후보 등록 후에는 사유/성공 메시지와 새봄로점 담당1행/후보없음을 함께 표시한다. 표시명에 점주라는 단어가 있어도 현재 계정 역할로 추정하지 않는다. 해당1280 화면은 높이720 계열임을 별도로 보존한다.

펼친 운영 감사에서 실제 QA 계정의OFC→점주/버전6→7/시험 담당 연결 종료를 수행자·시각·사유·성공과 함께 확인했다. 업무 원문이나 인증정보는 보이지 않는다. 앞선 담당 등록 성공과 권한 철회 화면의 후속 원상 복구 이력에 해당하며, 이 감사 화면 자체를 API 권한 검증으로 대신하지 않는다.

운영 재처리의 분석 중 화면은 첫 AI_UNAVAILABLE 실패와 둘째 실행 중 시도·수용/점유 기한·현재 미반영을 함께 보존한다. 성공 화면에는 둘째 완료/종료시각이 보이나 결과 반영 값은 아래여서 추가 구간을 요청했다. QA05 기준정보 분류 비활성은 사유/과거보존·신규 제한·영향0·저장 성공을 제공한다. 과거 Mock 장애의 최초 접수일부터 시간을 신규 분석 지연으로 집계하지 않는다.

## 운영 재처리 반영과 현재 권한 판정

추가 성공 구간에서 첫 실패는 미반영으로 남고 둘째 성공은 결과 반영예로 표시됨을 직접 확인했다. 수용/점유 기한과 성공 작업 재처리 불가 안내도 읽힌다. root의 합성 장애 재처리이며 과거 최초접수 기준 시간을 정상 신규 지연으로 계산하지 않는다.

최신 E04는 계정 비활성→기존세션 로그인, 매핑 종료→본문 제거, 점주→OFC 전환→기존경로 거부/현재 후보 등록, 복구 감사/연결 종료를 기록한다. 앞서 직접 본 정상 PNG와 일치한다. 별도 independent-http-review.md의 실제media_id 정상 원본200/hash/썸네일200 대비 운영자403·북부지역404도 확인하되 이 HTTP15개 결과를 Browser 조작과 혼동하지 않는다. D05-03/07 PASS이며 전체 인수/접근성/문서렌더는 아직 미완료다.

## 360 상태 구분과1280×800 보완

360의 Mock 판단불가는 실제AI가 아님을 명시하며 준수—/판단가능0%/0·4와 이유를 제공한다. 기술실패는 점수 계산 대상에서 제외하고 운영 복구/상태재조회를 안내한다. QA05 운영공지의 실제 점주 표시와 뒤이은 개선 후 이력100/100도 읽힌다. owner-empty 파일에는 아직 빈 결과가 보이지 않으므로 파일명으로 빈 상태를 선언하지 않는다. 이전1280 빈 이력 증거는 별도로 유지한다.

1280x800 운영 홈은 실제 저장1265×791이며 앞선720 높이와 구분해 추가viewport 증거로 확인했다. 운영 직접영업경로 거부도 별도 실제PNG에서 본문없음을 확인했다. 공지 편집 폼/미리보기는 읽히며 저장사유 값 자체는 root기록으로 대조한다.

## DR-QUEUED-001 공통 대기·통신 오류·복구 추가 검수

신규390 viewport4장을 직접 확인했다. 대기·추가 지연·통신 오류·복구 후 대기·worker 재시작 후 QUEUE_TIMEOUT 기술 실패가 서로 구분되며, 통신 오류나 기술 실패를 평가0점으로 표시하지 않는다. 이번 대기는 과거 시각을 넣은 별도 Mock fixture이고 실제 AI 호출/성능 측정이 아니다. 원본 질문에도 합성 검수임을 명시한다. 보이는 구간에서 새 명백한 겹침·글자 절단·본문 가로넘침은 발견하지 않았다.

root의 실제 조작 기록과 별도 READ ONLY 사후25PASS를 참조했다. 신규 시도는 expired·결과0·점유 없음, snapshot 보존이다. 기존15건 snapshot과 사전 결과hash가 있는12건의 결과 보존을 확인한 범위이며 DB 전수/모델 로그 검증으로 확대하지 않는다. 본인은 추가 Browser·DB·AI·서비스 조작을 하지 않았다. 화면 이탈 시 polling 종료, 목록 전체4상태, 입력/충돌/키보드/200%는 이번4장으로 완료 처리하지 않는다. 파일별 제한은 [evidence-index.md](evidence-index.md), 결합 보고서는 [DR-QUEUED-001](../../workHitory/design-review-queued/review-001.md).
