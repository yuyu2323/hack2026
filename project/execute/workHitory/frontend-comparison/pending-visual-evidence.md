# 최종 검수를 위해 남은 실행과 화면 증거

- 담당 contract_ai / 이 목록은 **최종 build/setup/start/preview 후속 기록 반영 후 동결**. 전체 제품 검수는 진행 중이다. root 원본 체크리스트는 수정하지 않았다.
- docs02·04·09와 각 acceptance를 유지한다. root만 Browser·공유 세션을 조작한다. 독립 시각 PASS와 root 기능 PASS를 구분한다.
- 실제200%는 사용자 “나중에 진행” 선택으로 **NOT_RUN(후행)**이다. 면제나 목표 중단이 아니며 viewport 변경으로 대체하지 않는다.

## 2. 남은 root 실행 — 기능별 중복 제거

1. **수정 화면의 아직 보지 못한 구간**
   - 01: 재제출 미리보기 로드 수정본, 전후 비교의 펼친 버전/오른쪽 변화 열, 운영 health/model 첫 화면 및 감사 after 전체. 연속필터/이름 표시 기능은 이미 PASS이므로 해당 동작을 다시 수행할 이유는 없다.
   - 02: Reference 번호1·2·3의 실제 카드 구간 **한 번만** 후속 촬영. `reference-number-fixed` 파일은 기준 accordion까지만 보이며 사진/번호가 화면 밖이다. 제품 재실패로 판정하지 않는다. 성공/진행 재처리 guard의 아직 보이지 않은 구간도 기존 정상 시도표를 반복하지 않고 확인한다.
   - 02의 옛 fullPage 증거 중 아직 대체되지 않은 영업 원본 근거/조치, 기준/Reference 관리 이력, 운영 첫 화면·분석 차트의 필요한 viewport만 보완한다. 업무 저장·실제AI는 재실행하지 않는다.
   - 03: 사진 우선 관제·버전 이력·비교 날짜/버전/키보드·해결 문구는 PASS. 펼친 감사 before/after의 아직 없는 시각 구간만 남는다.

2. **상태·입력·오류 복구 (E06)**
   - 화면 이탈 시 polling 종료, 아직 확인하지 않은 폼의409/CSRF·세션 오류와 중복 제출만 미완료로 유지한다. 01·02·04 Reference409의 입력/사진 보존→최신 조회→명시 재저장,01 기준409와01·02 CSRF 입력 보존은 실제 PASS이므로 반복하지 않는다. API 중단/복구와 QUEUE_TIMEOUT를 반복하지 않는다.
   - 입력 경계 중 정확10MiB/합계50MiB와 긴 기준 본문은 최신 root 검사에 미포함이다. 이미 완료한 형식·초과·6장·5장·순서/삭제·질문2000자는 반복하지 않는다. 제공된 새 사진 순서 PNG는 다음 독립 검수자가 검토할 수 있다.
   - 01: 빈 이력/매핑 없음·unknown·적용 기준/Reference 없음의 아직 없는 화면. 기술 실패/대기는 이번에 완료했다.
   - 02: 빈 이력/연결 없음·적용 기준/Reference 없음·긴 기준. 실제 unknown과 통신/기술 실패를 위해 새 AI를 요구하지 않는다.
   - 03: 빈 이력·Mock unknown·기술 실패·기준/Reference 없음·긴 질문/사진0장과 queued/통신은 완료. 전체 목록 최초/갱신/빈/오류 중 미확인 구간만 남는다.

3. **분석·알림·공지·목록 복귀 (E07)**
   - 01: 이름·Mock/n·분산0·n0/NULL과 필터/상세뒤로 복귀는 root 후속 PASS. 기본 리포트 및 공지 비활성 후 점주 비노출의 아직 없는 근거만 확인한다.
   - 02: Mock/n/기간리포트·n0/NULL·공지 게시/비활성 후 비노출은 완료. 분산0, URL/페이지 직접 복귀와 상세뒤로 유지의 아직 없는 구간만 남는다.
   - 03: Mock/n5·제외수·n0/NULL·알림·공지는 완료. 분산0/기본 리포트와 URL/페이지 복귀의 아직 없는 부분만 남는다.
   - 공통: 타수신자 알림 거부, 목록 재조회 중 기존 내용/갱신 표시 및 초점 비강제 이동은 근거가 있는 시안을 제외하고 확인한다.

4. **최종 실행·접근성 (E08)**
   - 최종5build 및 preview의 점주/본사/운영자 세 경로군 진입·새로고침, 새 탭 콘솔 warning/error0 확인은 완료했다. 옛 preview 대기 요구는 해소한다. 이 기록은 다섯 개 역할 각각의 모든 내부 URL·요청·전체화면 디자인 전수 검수는 아니며 HMR 과거 오류와 구분한다.
   - 1280×800(720과 구분),01 명세320/768/1024 및 아직 없는 핵심 키보드/오류 연결·44px·긴 문구·내부 표 스크롤만 보완한다. 기존390/360/1440 정상 화면 전체를 재촬영하지 않는다.
   - 실제200%는 후행이며 전체 목표의 미완료 항목으로 유지한다.

## 3. 04·05에서 유지할 잔여 범위

- **04**: 실제 첫/child·기준/Reference 이력·5역할/운영복구·D04-V01/V02 수정은 PASS. 이번 queued/API 복구/timeout과 root 입력 경계도 완료했다. 미제출 대표 카드·분산0/기간 리포트·지역/매장 기준정보 관리, Reference409 복구와 최종 preview 세 경로군은 완료했다. 아직 없는 목록4상태/다른 충돌/키보드·표 명명은 별도다.
- **05**: 실제60→100/비교·조치/점주 알림·권한철회/담당등록/감사·실제 재처리·공지·Mock unknown·n0/분산0 및 이번 queued/API/timeout·입력 경계 완료. 최종 preview 세 경로군은 완료했다. 복사 URL 직접 재현/상세 복귀·기준/Reference 이력 전체는 실제 완료 근거가 충분하지 않아 미확인으로 유지한다. 나머지 필수폼/충돌/CSRF·전체 키보드는 별도다. 흰 first-result는 제외하고 fixed를 사용한다.

## 4. 인계 원칙

원본 캡처를 보존하고 실제 viewport·decoded 치수·역할/상태·소스 대응을 기록한다. 화면 밖을 제품 결함으로 표시하거나 DOM 존재로 시각 PASS를 주지 않는다. 실제 API/이미지 경계는 유효 media ID의 허용200 baseline과403/404를 연결한다. 비밀번호·토큰·세션 값은 기록하지 않는다. 매뉴얼 이미지 구성01 8/02 7/03 10/04 10/05 12장은 이번 작업에서 바꾸지 않았다.

## 최종 실행·복구 후속 정정

- root의 [5개 build](../final-handoff/build-all.log), [setup 재실행](../final-handoff/setup-rerun.log), [시작](../final-handoff/start.log), [중복 시작](../final-handoff/start-idempotent.log), [preview](../final-handoff/preview-browser.json)를 읽기 대조했다. 기본 시연 DB `storeloop`에서 setup 완료·시드 기존263건 보존, 공통3서비스+5시안 시작, 재실행은 이미 실행 중으로 처리됐다. 최종 stop→실제 종료 확인→restart는 후속 [runtime 기록](../final-handoff/runtime.md)에서 완료됐다.
- preview 기록은5시안×점주/본사/운영자15개 역할·시안 조합을 포함한다. 최초 진입은 direct/login으로,01점주는 reload로 보존된 차이가 있으며 모든 조합의 reload가 있다. 일부 즉시 snapshot은 로딩 상태를 포함하므로 데이터 완전 렌더나 모든 필수 요청 성공까지 확대하지 않는다. root의 실제 경로군 진입/새로고침과 새 탭 warning/error0 확인을 반영했으며 새 AI 호출은0이다. 본인의 새 Browser/PNG 검수는 없다.
- [입력·복구 실제 기록](../input-boundary/browser.md):02 Reference v1→다른 창v2→CSRF/409→입력·파일 유지→명시v3,01 기준v2→다른 창v3→409 초안/사유 보존→명시v4,01 Reference 명시v5,04 최신v6 확인→입력·파일 유지→명시v7 성공. 합성 Reference lineage는 비활성 정리됐다. 01의 알려진 두 경쟁/권한 결함도 기존 독립2회귀 PASS로 해소했다.
- 이 정정은 옛 최종 preview 대기와 위 복구 단계만 해소한다. 안 본 전체 디자인, 실제200%·나머지 미실행을 PASS로 바꾸지 않는다. 사용자 요청에 따라 추가 실행이나 검수 범위 확대 없이 두 문서를 동결했다.


2026-09-21 정정: 05의 복사 URL·상세 복귀를 근거 없이 완료로 바꾼 이전 문구를 되돌렸다. 정본 D05-02의 미확인 상태를 유지한다. 새로운 제품 실패가 아니라 증거 범위 정정이다.
