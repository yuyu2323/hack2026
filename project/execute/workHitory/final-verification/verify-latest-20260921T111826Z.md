- PostgreSQL 검사는 `postgres_db` fixture가 `_test` DB의 매번 다른 `test_UUID` 스키마를 만들고 finally에서 제거하는 경로를 사용했다. 브라우저용 public 데이터·`.local/test-media`를 reset하거나 변경하는 별도 명령은 실행하지 않았다.
- 실제 AI marker는 명령에서 제외했고 AI 단위 검사는 executor/HTTP fixture다. 현재 QA API/AI/worker/Vite/PG 프로세스와 브라우저를 시작·중지·재설정하지 않았다.

- 확인용 `ps` 조회는 기본 sandbox에서 권한 거부되었고 재시도하거나 현재 프로세스를 조작하지 않았다. 이는 전체 verify의 실패가 아니며, 승인된 로컬 PG 검증 프로세스는 정상 완료했다.
