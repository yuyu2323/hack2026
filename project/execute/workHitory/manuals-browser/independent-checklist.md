# 매뉴얼 PNG 독립 시각검수 체크리스트

- 담당: contract_data. HTML 원저자와 분리한 PNG 검수이다.
- 허용 범위: root가 Browser로 생성한 5개 시안의 데스크톱·모바일 PNG, 02 표 수정본, 기존 DOM 관측 읽기.
- 변경 범위: 이 디렉터리의 `independent-*` 기록만. HTML·이미지·Browser·서비스를 변경하지 않는다.
- [x] 각 시안 데스크톱·모바일 최소 1장씩 직접 열어 확인한다. 총 22장 확인.
- [x] 02 `mobile390-table-fixed`를 직접 확인한다.
- [x] 가독성, 화면 잘림, 깨진 이미지, 초점, 표, 캡션의 결함을 확인한다.
- [x] PNG 파일 해시와 직접 관측을 남기고, 기존 DOM 관측과 구분한다.
- [x] 발견 사항과 미검증 범위를 root에게 인계한다.
- [x] D-MAN-H01 상단 저대비 수정 후 최신 캡처를 재판정했다. 새 10장 PASS_WITH_NOT_RUN, 02 로그인 ID 중간 분할도 해소.
- 200% 확대: 사용자 후속 진행 선택에 따라 NOT_RUN. 모바일 viewport로 대체 판정하지 않는다.
- 01/03 상단 캡처의 명령 문구는 변경 전일 수 있어 레이아웃만 검수한다. 최신 문구 재캡처는 root 담당이다.
