root는 앞서 수정한 검증 보고서 표현을 원본 사용자 전용 백업과 대조했다. source_before/source_after 각각216개 해시와 나머지 모든 결과 필드가 그대로 보존되어 있다. [정규화 대조 결과](security-report-preservation.json). 검사 규칙이나 테스트 결과는 변경하지 않았다.

## 01 운영 화면의 미촬영 구간

최종 preview에서 기능·DOM을 확인했으나 독립 시각 근거가 없던 운영 상태의 두 구간만 추가 촬영했다. 일반 시연 DB, operator.demo, /platform-admin, 최종 소스의 dev 화면이다. 기존 Mock 자료 조회만 수행했고 데이터 변경·서비스 조작·AI 호출은 없다.

- [상단](vp-desktop1440-concept01-health.png): 실제 작업 지표와 API·DB·AI 프로세스·worker 가동 상태 및 heartbeat를 읽을 수 있다.
- [하단](vp-desktop1440-concept01-model.png): 프로세스 가동과 모델 사용 가능의 차이, 마지막 모델 성공/실패 없음과 판단 불가, 분석 미실행 안내와 연결 정보를 읽을 수 있다. 실제 저장 파일의 Mock 카드 구간은 흰 영역이므로 해당 수치를 시각 확인한 근거로 쓰지 않는다. 별도 Mock 25/7은 DOM 기록으로만 확인했다. 모델 준비를 성공으로 추정하지 않았다.
- viewport1440×900, document1425px, 실제 저장1425×891. 페이지 가로넘침 없고 새 검수 탭 warn/error0. 촬영 후 탭을 닫고 viewport를 복원했다.
- [DOM·실제 치수·콘솔](concept01-health-evidence.json), [원본 이미지 hash·decoded 치수](concept01-health-images.json). 독립 디자인 판정은 별도 정본에 기록한다.

매뉴얼 자체와 앱 코드는 변경하지 않았다. 200% 확대와 남은 미확인 항목은 기존 상태로 유지한다.
