# 최종 StoreLoop 시안 선택
- 상태: 사람의 최종 선택 대기. 구현·검증·인계 작업은 선택과 독립적으로 진행한다.
- 문제: 같은 기능을 제공하는 다섯 정보 구조 중 실제 운영에 사용할 구성을 정해야 한다.
- 영향: 선택한 시안을 이후 제품 개선의 기준으로 삼는다. 선택하지 않은 시안도 현재 산출물로 보존한다.
- 선택지: 01 관제 데스크 / 02 오늘 할 일 / 03 사진·근거 탐색 / 04 현장 포켓 / 05 탐색·비교 작업영역.
- 권장안: 관제 업무가 주목적이면 01, 점주의 반복 촬영이 주목적이면 04를 우선 비교한다. 최종 선택은 실제 화면과 역할별 동선을 확인한 사람이 결정한다.
- 비교 자료: [다섯 시안 비교](../../../deliverables/frontend-comparison.md)
- 결정: 미정. 이 문서는 구현 중 자동 선택을 뜻하지 않는다.
