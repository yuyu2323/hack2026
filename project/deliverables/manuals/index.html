역할별 시작

  • 점주 — owner.north 또는 owner.south: 사진 제출, 결과·재피드백, 문의·알림.
  • OFC — ofc.north 또는 ofc.south: 담당 매장, 기준·Reference, 이슈 조치.
  • 지역·본사 — regional.north, regional.south, hq.demo: 지역·전사 현황과 분석.
  • 플랫폼 운영자 — operator.demo: 계정·연결·기준 정보·공지·실패 작업 복구.

비밀번호는 프로젝트의 사용자 전용 .local/demo-credentials에서 확인합니다. 역할을 바꿀 때는 로그아웃 후 로그인하세요. 같은 호스트의 탭은 로그인 상태를 공유합니다.

추천 시연 순서

  1. 점주로 로그인하고 매장·카테고리를 선택합니다.
  2. 제공된 before 사진과 질문을 제출하고 분석 결과를 읽습니다.
  3. 같은 결과에서 after 사진으로 재제출한 뒤 전후 변화를 비교합니다.
  4. OFC로 로그인해 해당 기록의 문의·조치를 확인합니다.
  5. 점주로 돌아와 해결 이력과 알림을 확인합니다.
  6. 운영자로 계정·처리 상태와 감사 이력을 확인합니다.

기존 결과로 먼저 시연하면 모델 응답을 기다리지 않고 화면을 둘러볼 수 있습니다. 새 사진을 제출하면 실제 AI가 호출됩니다.

로컬 실행

프로젝트 폴더 hack2026/project에서 실행합니다. 처음 준비할 때는 첫 번째 명령을 사용하고, 이미 준비됐다면 시작 명령부터 실행합니다.

./scripts/setup.sh
./scripts/start.sh --concept 1 --concept 2 --concept 3 --concept 4 --concept 5

Node 22.12+, npm 10+, Python 3.11+, PostgreSQL 14+와 로그인된 Codex CLI가 필요합니다. 다른 터미널에서 같은 포트의 서버를 실행 중이면 먼저 그 실행 창에서 종료하세요. 현재 실행 화면은 일반 시연 DB를 사용합니다. 기존 실제 AI 인수 증거는 별도 테스트 DB에 보존되어 있습니다.

./scripts/stop.sh는 종료 신호를 보낸 뒤 반환합니다. DB를 중지하기 전에 서비스 프로세스의 종료를 확인하세요.

확인한 범위

5개 시안의 실제 AI 제출·재제출, 주요 권한·조치·복구 흐름과 매뉴얼의 데스크톱·모바일 화면을 확인했습니다. 사진과 매출 자료는 합성 시연 자료이며, Mock 과거 기록과 실제 AI 결과를 구분합니다.

실제 AI 분석은 30초 목표를 초과한 사례가 있으며, 시안별 매뉴얼에 측정값을 적었습니다. 사용자 결정에 따라 이번 구현·매뉴얼 인계를 마무리했습니다. 200% 확대와 일부 키보드·목록·관리 화면 세부 검수는 후행 항목으로 남겼으며, 미검수 항목을 통과로 표시하지 않았습니다.
